# 在线算法刷题平台

一个纯前端、开箱即用的中文算法刷题网站，体验类似 LeetCode。支持 **218 道 ACM 模式编程题**（Python 3 在线判题）与 **100 套 / 2000 道选择题**（按公司分卷、整套作答与批改）。

## 功能特性

### 编程题（218 道）
- Python 3 · ACM 模式：从标准输入读取数据，用 `print()` 输出，判题按「输入文本 → 输出文本」逐用例比对
- 覆盖 LeetCode 热题 100 常见范围、大厂高频题与华为真题风格题
- 按难度（简单 / 中等 / 困难）与公司（华为、字节、腾讯、阿里、美团、移动、通用）筛选
- 代码区默认空白，从 `import` 开始自己写完整程序；可选「插入 ACM 模板」
- 编辑器智能缩进：冒号后回车自动缩进、换行保持缩进、Tab / Shift+Tab 多行缩进
- 在线判题基于 [Pyodide](https://pyodide.org/)（浏览器内运行的 Python），运行时已打包在 `pyodide/` 目录，**无需联网即可判题**

### 选择题（100 套 / 2000 道）
- 按公司与方向分卷：华为、字节、腾讯、阿里、美团、百度、中国移动、408、专项卷等
- 公司筛选 + 可滚动试卷列表，快速定位试卷
- 单题作答：点题目切换、单选选项，全部作答后统一提交批改
- 提交后显示得分、你的答案、正确答案与逐题解析

### 通用
- 统一的题目列表与题型按钮，搜索 + 每页 20 条分页
- 代码、答题记录与进度保存在浏览器 localStorage，刷新不丢
- 纯静态站点，无后端、无登录，可直接双击 `index.html` 打开

## 目录结构

```
.

├── problems.js     # 218 道编程题题库（题意、用例、参考解答）
├── mcqs.js         # 100 套 / 2000 道选择题题库
└── pyodide/        # Pyodide 运行时（本地判题，约 13.5MB）

    ├── pyodide.asm.js
    ├── pyodide.asm.wasm
    ├── pyodide-lock.json
    └── python_stdlib.zip
```

## 使用方法

直接用浏览器打开 `index.html` 即可。若浏览器对 `file://` 协议下的 Worker 有限制，可在项目目录启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

顶部切换「编程题 / 选择题」：
- 编程题：从左侧选题 → 在右侧写代码 → 点「运行」看用例结果，或「提交」判题
- 选择题：切到选择题 → 选一套试卷 → 逐题作答 → 点「提交批改」

## 题库说明

- 编程题的参考解答均通过本地 `python3` 跑通各自 ACM 测试用例
- 选择题中参数化题目（进制、位运算、二叉树、子网、调度等）的答案由脚本精确计算，概念题经人工核对
- 内容为原创整理，未复制受版权保护的原文

## 在线版本

已发布为静态站点，可通过分享链接在任意设备访问（进度按浏览器本地保存，不跨设备同步）。
